# Research Dossier — index

Primary-source research behind the product, retrieved 2026-08-27. Every file opens with a plain-English summary, labels each fact's confidence, and ends with what must be re-verified before code depends on it.

**Read the method note once:** this research environment could not open web pages directly (a network proxy blocked it), so facts were gathered from search-engine retrieval of the cited official pages, cross-checked across sources. Everything load-bearing carries a label — **OFFICIAL** (government/legislation source), **WEAK** (vendor/blog/review site), **UNVERIFIED** (could not be confirmed) — and each file lists exactly what to re-check by opening the primary documents in an ordinary browser before Stage 1 builds on it.
