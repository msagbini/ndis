# Customer Interview Kit — read this first

This folder contains everything needed to run the Stage 0 validation interviews. The interviews are the one part of Stage 0 only a human can do: real buyers need to hear a real person. Everything around the conversations — finding people, the words to say, the analysis — is prepared here so the founder's only job is to have the conversations.

## The five files and the order to use them

| Step | File | What it's for |
|---|---|---|
| 1 | `finding-people.md` | Where to find NDIS providers and plan managers to talk to, with named sources and links. Build a list of ~40 prospects into `prospect-list-template.csv`. |
| 2 | `outreach-messages.md` | Exact messages to send — email, LinkedIn, and a phone opener. Copy, personalise two fields, send. |
| 3 | `interview-script.md` | The script to read from during the call, almost verbatim. Questions marked ★ are the essential ones if the call gets cut short. |
| 4 | `note-taking.md` | The template to fill in during or immediately after each call. No apps to set up. |
| 5 | `scoring-sheet.md` | **Not the founder's job.** Hand the raw notes back to the agent (paste them into the chat); the agent fills in the scoring sheet and computes the verdict against `docs/go-no-go.md`. |

## The target

At least **10 completed interviews** with decision-makers or day-to-day operators at:

- NDIS providers with roughly 5–50 staff (owners, operations managers, finance/claims officers), and/or
- NDIS plan managers (a plan manager is a business that pays providers' invoices on behalf of NDIS participants, so they process claims in volume).

Expect roughly 40 outreach attempts to get 10 conversations — a 25% hit rate is normal and not a failure.

## Standing offer: rehearsal before the first real call

Before making the first real call, ask the agent to rehearse. The agent will role-play a sceptical, busy provider — including interruptions, vague answers, and "we already have software for that" — and then give feedback on pacing and follow-ups. Do this at least once; the first real call should not be the first time the script is read aloud.

## Two rules for the calls

1. **This is not a sales call.** Nothing is being sold; there may not even be a product. The moment it sounds like selling, people stop telling the truth about their problems.
2. **Their words, not ours.** Never suggest the answer ("so claims rejections must be a nightmare, right?"). Ask, then be quiet. The script shows how.
