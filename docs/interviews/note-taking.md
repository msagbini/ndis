# Note-Taking — zero setup

No apps, no transcription services. Notes go into a plain text file or straight into the chat with the agent afterwards. The scoring is the agent's job; the founder's job is only to capture what was said.

## During the call

Type (or handwrite) fragments — not sentences. Capture **their words** for anything vivid: if they say "the portal just eats claims", write exactly that in quotes. Verbatim quotes are worth ten paraphrases.

If typing during the call is distracting, don't. Do the call, then immediately — before the next email, before coffee — spend 10 minutes filling in the template below from memory. Memory of a call halves by the end of the day.

If they consented to recording (see the script — consent required, always): record with whatever is at hand (phone voice memo on speakerphone is fine), still fill in the template afterwards, and note "recording exists" at the top. Delete recordings once notes are written up.

## Handing notes back

Paste each completed template into the chat (or commit the file and say so). The agent then fills in `scoring-sheet.md`, keeps the running tally against the go/no-go threshold, and flags anything worth a follow-up question by email. Raw notes are never edited by the agent — scoring happens in the scoring sheet, so the source stays clean.

**Privacy note:** these notes contain business information given in confidence, and never participant data. Keep names out of anything public; inside this private repo, org names are fine and useful.
